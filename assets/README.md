# Apple Root CA

`apple-root-ca.pem` is Apple's public `Apple Root CA` certificate, downloaded from Apple's
[PKI repository](https://www.apple.com/certificateauthority/) at
`https://www.apple.com/appleca/AppleIncRootCertificate.cer` and converted from DER to PEM.

Certificate details:

- Subject: `C=US, O=Apple Inc., OU=Apple Certification Authority, CN=Apple Root CA`
- Serial: `02`
- Validity: 2006-04-25 through 2035-02-09
- SHA-256: `B0:B1:73:0E:CB:C7:FF:45:05:14:2C:49:F1:29:5E:6E:DA:6B:CA:ED:7E:2C:68:C5:BE:91:B5:A1:10:01:F0:24`

The fingerprint is published in Apple's
[root-store documentation](https://support.apple.com/en-us/126047).
